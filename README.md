# Hypothesis Testing Assignment

## Overview
This repository contains solutions to a comprehensive **Hypothesis Testing Assignment**. The objective of the assignment is to deepen understanding of statistical hypothesis testing, including:

- Formulating null and alternative hypotheses
- Selecting significance levels
- Understanding p-values
- Conducting one-sample and two-sample t-tests
- Conducting right-tailed, left-tailed, and two-tailed tests
- Interpreting Type I and Type II errors
- Drawing conclusions from test results

The assignment includes step-by-step solutions for covering both conceptual and practical applications of hypothesis testing.
